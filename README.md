# Apul Engineering (Consultancy) Paramarsha Sewa Website

A responsive single-page website for **Apul Engineering (Consultancy) Paramarsha Sewa**.

## Run locally

No build step or dependencies are required. Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — page content and semantic structure
- `journey.html` — founder story, company growth, and milestone timeline
- `careers.html` — single-screen vacancy status and hiring principles
- `enquiry.html` — project enquiry form with email, phone, and WhatsApp options
- `portal.html` — restricted client login and planned workspace overview
- `privacy.html` — website privacy policy and data-handling disclosures
- `terms.html` — terms governing website access and use
- `abbreviations.html` — full forms and contextual definitions used across the website
- `styles.css` — responsive layout, visual system, and animations
- `journey.css` — responsive styling for the Our Journey page
- `careers.css` — responsive styling for the Careers page
- `enquiry.css` — responsive styling for the enquiry experience
- `enquiry.js` — form validation and pre-filled contact-message generation
- `portal.css` — responsive styling for the portal preview
- `privacy.css` — responsive styling for the Privacy Policy page
- `terms.css` — Terms and Conditions page refinements
- `abbreviations.css` — responsive styling for the abbreviations directory
- `portal.js` — login feedback and client-access policy interactions
- `script.js` — mobile navigation, reveal animations, and current year
- `assets/engineering-hero.png` — original generated hero artwork
- `assets/apul-engineering-logo.png` — official company logo used in the header and footer
- `assets/portal/` — Jira, 2FA, and reCAPTCHA portal trust images
- `assets/banking/` — official banking and accepted payment-channel logos

Contact details and service copy are initial placeholders and should be replaced with verified company information before publishing.
